## Sprint 1
- [ ] Como gestor, quero um planejamento bem estruturado e esboços no papel que atendam as minhas necessidades.
- [ ] Como analista, quero que os dados estejam limpos e organizados no Google Colab para uma boa interpretação.
- [ ] Como usuário, quero os códigos eficientes e comprenssíveis para um sistema confiável e funcional no Google Colab.
- [ ] Como gestor, quero um esboço do trabalho já criado Canva.
- [ ] Como usuário, quero uma revisão de todo trabalho com os código para tudo ficar funcional.

## Sprint 2
- [ ] Como gestor, quero receber esboços de gráficos de colunas empilhadas referentes ao total de exportações de cada município do estado de São Paulo no Power BI para visualizar os dados de forma inicial.
- [ ] Como analista, quero visualizar gráficos de linhas e desgin desenvolvidos no canvas com base nos dados de exportação.
- [ ] Como gestor, quero obter gráficos de colunas no canvas que incluam  medidas de dispersão para realizar análises detalhadas.
- [ ] Como tomador de decisões, quero os gráficos realizados no Canva e no Power BI revisados e finalizados construídos para uma boa confiabilidade.
